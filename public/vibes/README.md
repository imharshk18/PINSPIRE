# Pinspired launch vibes

Drop visual assets into one folder per launch vibe:

- `mediterranean-summer/`
- `scandi-warmth/`
- `eclectic-vintage/`
- `coastal-grandma/`

For each vibe, include 5–12 landscape or portrait JPG/PNG/WebP images. Use images you own or are allowed to use. The new browse screen will render them as a rounded masonry mood board, and its corresponding pre-created Arcade products will appear below it.

Optional names for the files:

- `hero.*` for the lead mood-board visual
- `room.*` for the default decorated-room visualization
- any remaining images for the board cards
